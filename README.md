Grading Database System
Microsoft Access | SQL

Overview: The Grading Database System is a relational database designed to manage and analyze student academic performance. The database organizes student information, grades, deliverables, deliverable types, attendance, and class sessions across six related tables. Primary and foreign keys were used to establish relationships between the tables and maintain a structured database design. 

SQL Analysis: SQL was used to retrieve and analyze information across the related tables. The project includes queries that use INNER JOIN to combine student, grade, deliverable, and deliverable type information. Additional SQL queries were developed to calculate average scores by deliverable type, attendance percentages, and weighted final course percentages. The queries also demonstrate the use of filtering, grouping, and aggregate functions such as AVG(), SUM(), and COUNT(). 

Database Interface: A Microsoft Access form called FrmGradesEntry was created to provide an interface for entering and managing student grade information.

Skills Demonstrated: This project demonstrates experience with SQL, Microsoft Access, relational database design, SQL joins, aggregate functions, data analysis, primary and foreign keys, and database relationships.

Project Purpose: The purpose of this project was to demonstrate how a relational database and SQL can be used to organize academic data and turn student grades and attendance records into meaningful performance metrics, including average scores, attendance percentages, and weighted final course percentages.
